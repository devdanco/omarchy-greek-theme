# omarchy-greek-theme

A dark Omarchy theme inspired by Greece — the Aegean Sea, white marble, golden sun, olive groves, bougainvillea, and the blue of the Greek flag.

## Preview

![Greek Theme Preview](preview.png)

## Colors

| Role | Color | Inspiration |
|------|-------|-------------|
| Background | `#0d1b2a` | Midnight Aegean sea |
| Accent | `#1d6fa4` | Hellenic blue (Greek flag) |
| Foreground | `#e8e4d9` | White marble |
| Green | `#6b7c4a` | Olive tree |
| Yellow | `#e8b84b` | Aegean sun gold |
| Red | `#c0513a` | Terracotta / ancient pottery |
| Cyan | `#4db8c0` | Crystal Aegean water |
| Magenta | `#c0537a` | Bougainvillea pink |

## Backgrounds

Includes 4 high-resolution wallpapers:

- Santorini blue domes
- Aegean sea
- Acropolis
- Mykonos whitewashed village

## Install

```bash
omarchy theme install https://github.com/your-username/omarchy-greek-theme.git
```
